DEATH is the permanent termination of CORPIFORM as a governed execution-control component.

Once dead, CORPIFORM:

- must not execute
- must not accept authority for new consequence
- must not emit new receipts or denials as live operational outputs
- must not be reactivated

- must not be silently replaced in place as if continuity still existed

Death is not suspension.
Death is not freeze.
Death is not rollback.
Death is the end of live governed execution legitimacy for this system identity.

is a **release-boundary surface only**.

It records canonical repository state, but it does not itself kill the system, revive the system, or substitute for an explicit terminal event.

Death must be established through explicit canonical terminal conditions, not by misreading release metadata.
